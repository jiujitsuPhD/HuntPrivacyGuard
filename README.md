Hunt’s Privacy Guard helps users block submissions containing terms on their protected list.

To use, download .zip file and add to chrome extension. 

1. Extract the ZIP file
2. Open the Extensions page in google chrome - chrome://extensions
3. Look for the Developer mode toggle switch in the top-right corner of the chrome://extensions page. Click the toggle to turn it on
4. Click the Load unpacked button that appears in the top-left area of the page. Navigate to and select the folder where you extracted your extension files (do not select the original .zip file itself). Click Select Folder (or Open) to install the extension.
